# Running Chart Web Application - System Specification & Requirements ## Overview A digital counterpart to a physical fleet / vehicle running chart logbook. Features a high-fidelity dashboard, dual-side physical book logbook viewer (Side 1 trips + Side 2 fuel tables), responsive quick trip entry form (optimized for mobile/desktop), unified trip history data table, vehicle profile & telemetry setup, and Excel book-mirror export. ## Key Logic & Business Rules 1. **Physical Book Pagination Rules:** - 4 days per page max. Up to 13 trips per day. - New calendar month always triggers a fresh page break. - Odometer Continuity: End KM of Page N = Start KM of Page N+1. - Fuel Continuity: End fuel balance of Page N = Fuel position of Page N+1 Day 1. - Rounding: Distances, fuel balances, and calculated consumption to 1 decimal place. 2. **Side 1 (Trips Log):** - Date + Day of week display - Start Time, End Time, Start KM, End KM, Trip Distance (reciprocal calc) - Trip Type: Official vs Private - Places Visited, Optional Fuel Pumped (Liters) + Fuel Order No. 3. **Side 2 (Fuel & Consumption Tables):** - Table 1: Fuel Economy & Consumption (Start KM, End KM, Distance, Fuel Economy km/L) - Table 2: Fuel Position & Balance (Fuel Position Start, In-Tank, Drawn Fuel, Order No/Date, Consumed Amount = Dist/Econ, Balance End) 4. **Platform Form Factor Notes:** - Data Entry: Designed with high mobile responsiveness and quick-input tap pads. - Dashboard, Book Pages View, and All Trips: Desktop-optimized master views.
